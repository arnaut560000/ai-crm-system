# Screenshot Plan

Capture these screenshots from a clean WordPress install before public release.

## Required Screenshots

1. Dashboard overview with metrics and leads table.
2. Add lead form opened.
3. Edit lead form with activity history.
4. CSV import panel.
5. Bulk actions in the leads table.
6. Settings page.

## Screenshot Guidelines

- Use sample data, not real customer information.
- Keep the browser zoom at 100%.
- Use a desktop width around 1440px.
- Crop only browser chrome if needed.
- Save images into `screenshots/`.

## Suggested Filenames

- `screenshots/dashboard-overview.png`
- `screenshots/add-lead-form.png`
- `screenshots/edit-lead-activity.png`
- `screenshots/csv-import.png`
