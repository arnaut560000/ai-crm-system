# Known Limitations

AI CRM System 1.5.1 is suitable for private beta and client demos, but it is not yet a polished marketplace v1.0 product.

## Current Limitations

- Admin-only access through `manage_options`.
- No custom CRM roles yet.
- No automated PHPUnit or browser test suite.
- No dashboard charts yet.
- No email reminders or notifications yet.
- No duplicate lead detection yet.
- CSV import is intentionally simple and expects a clear header row.
- No public product screenshots have been captured yet.
- No payment/licensing system is included.

## Recommended Before Public Sale

- Add screenshots.
- Test the ZIP on a clean hosted WordPress install.
- Test with PHP 8.1 and PHP 8.2.
- Add duplicate email warnings.
- Add role/capability settings.
- Add a lightweight onboarding screen.
