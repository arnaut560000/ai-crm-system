# AI CRM System 1.6.1 Release Notes

AI CRM System 1.6.1 refines the analytics dashboard after review.

## What's Changed

- Status Distribution now shows a lead mix view with percentages.
- Added active, won, and lost health percentages to make the status data easier to understand.
- Pipeline Value now uses a simple column graph for open, won, and lost value.
- Dashboard analytics copy was tightened so each panel explains a useful CRM question.

## Testing Checklist

1. Upload `dist/ai-crm-system-1.6.1.zip` through WordPress.
2. Activate or update the plugin.
3. Open `AI CRM`.
4. Confirm Status Distribution shows the stacked lead mix and percentages.
5. Confirm Pipeline Value shows three graph columns: Open Pipeline, Won Deals, and Lost Deals.
6. Add or update leads with different statuses and deal values.
7. Refresh the dashboard and confirm the analytics update.
