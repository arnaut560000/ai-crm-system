# Product Page Draft

## Headline

AI CRM System for WordPress

## Short Description

A lightweight CRM dashboard inside WordPress for managing leads, follow-ups, notes, imports, exports, and sales pipeline status.

## Key Benefits

- Keep leads inside WordPress admin.
- Track status, follow-up dates, deal value, and notes.
- Import and export CRM data with CSV.
- Use bulk actions to manage leads faster.
- Configure currency, default status, and records per page.

## Ideal Users

- Freelancers
- Small businesses
- Local service providers
- Agencies managing simple lead pipelines
