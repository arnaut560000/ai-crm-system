# Installation Guide

## Upload ZIP

1. Download `dist/ai-crm-system-1.5.1.zip`.
2. In WordPress admin, go to `Plugins > Add New`.
3. Click `Upload Plugin`.
4. Choose the ZIP file.
5. Click `Install Now`.
6. Activate `AI CRM System`.
7. Open `AI CRM` in the admin sidebar.

## Manual Install

1. Copy the `ai-crm-system` folder into `wp-content/plugins/`.
2. Activate the plugin from `Plugins`.
3. Open `AI CRM`.
4. Configure defaults under `AI CRM > Settings`.

## First Setup

1. Set your currency symbol.
2. Choose the default lead status.
3. Choose how many leads appear per page.
4. Leave uninstall cleanup disabled unless you intentionally want CRM data removed when uninstalling.
