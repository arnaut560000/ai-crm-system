# Support Guide

## Recommended Support Scope For Beta

For this beta release, support should cover:

- Installation problems.
- Activation errors.
- Dashboard display issues.
- Lead add/edit/delete problems.
- CSV import/export issues.
- Settings and uninstall behavior.

## Information To Request From Users

Ask users for:

- WordPress version.
- PHP version.
- Browser name.
- Screenshot of the issue.
- Exact steps that caused the issue.
- Sample CSV file if the issue is related to import.

## Suggested Beta Support Terms

- Beta users should expect fast fixes for blocking bugs.
- Feature requests should be collected but not guaranteed immediately.
- Users should back up their WordPress database before importing large lead lists.

## Known Safe Response

If a user reports a critical error, ask them to copy the full WordPress error message or send a screenshot. Then reproduce the issue on a local test install before shipping a fix.
