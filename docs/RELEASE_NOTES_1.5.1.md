# AI CRM System 1.5.1 Beta Release Notes

## Release Type

Private beta / client-demo release.

## Package

- ZIP: `dist/ai-crm-system-1.5.1.zip`
- SHA256: `0A5125248BF914CE15335FB677EA28A1725776B06B061683D39EBA0B5ED9551E`

## Highlights

- WordPress admin CRM dashboard.
- Add, edit, delete, search, and filter leads.
- Bulk status changes and bulk delete.
- CSV import and export.
- Follow-up date tracking.
- Deal value tracking.
- Notes and activity history.
- Settings for currency, default status, records per page, and uninstall cleanup.

## Install

Upload `dist/ai-crm-system-1.5.1.zip` through `Plugins > Add New > Upload Plugin`, then activate `AI CRM System`.

## Known Limitations

- This is not yet a public marketplace v1.0 release.
- No automated test suite is included yet.
- Screenshots still need to be captured from a real WordPress install.
- Access is currently admin-only through `manage_options`.
- Import supports basic CSV files and should be tested with customer data before production use.

## Recommended Next Step

Install the release ZIP on a clean WordPress site and complete `RELEASE_CHECKLIST.md`.
